# reportingBounds_country Dataset

**\[stable\]**

## Usage

``` r
reportingBounds_country
```

## Format

A data frame with 15180 rows and 8 columns:

- Threshold:

  number of standard deviations that the upper and lower bounds are
  based on

- Denominator:

  calculated denominator value

- LogDenominator:

  calculated log denominator value

- Numerator:

  calculated numerator value

- Metric:

  calculated rate/metric value

- MetricID:

  unique metric identifier

- StudyID:

  unique study identifier

- SnapshotDate:

  date of the snapshot

## Source

Generated from `reportingBounds_country.csv` dataset in the `gsm`
package.
