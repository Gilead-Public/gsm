# analyticsInput Dataset

**\[stable\]**

## Usage

``` r
analyticsInput
```

## Format

A data frame with 373 rows and 6 columns:

- SubjectID:

  unique subject identifier

- GroupID:

  grouping variable

- GroupLevel:

  level of grouping variable

- Numerator:

  number of flags in group

- Denominator:

  total subjects in group

- Metric:

  calculated rate/metric value

## Source

Generated from `analyticsInput.csv` dataset in the `gsm` package.
