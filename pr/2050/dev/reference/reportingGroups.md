# reportingGroups Dataset

**\[stable\]**

## Usage

``` r
reportingGroups
```

## Format

A data frame with 2802 rows and 4 columns:

- GroupID:

  grouping variable

- GroupLevel:

  level of grouping variable

- Param:

  Parameter of interest for the group

- Value:

  Value of specified Param

## Source

Generated from `reportingGroups.csv` dataset in the `gsm` package.
