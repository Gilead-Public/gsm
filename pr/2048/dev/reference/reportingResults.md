# reportingResults Dataset

**\[stable\]**

## Usage

``` r
reportingResults
```

## Format

A data frame with 15524 rows and 10 columns:

- GroupID:

  grouping variable

- GroupLevel:

  level of grouping variable

- Numerator:

  number of flags in group

- Denominator:

  total subjects in group

- Metric:

  calculated rate/metric value

- Score:

  statistical score

- Flag:

  ordinal flag to be applied

- MetricID:

  unique metric identifier

- StudyID:

  unique study identifier

- SnapshotDate:

  date of the snapshot

## Source

Generated from `reportingResults.csv` dataset in the `gsm` package.
