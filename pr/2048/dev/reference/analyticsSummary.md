# analyticsSummary Dataset

**\[stable\]**

## Usage

``` r
analyticsSummary
```

## Format

A data frame with 154 rows and 7 columns:

- GroupID:

  grouping variable

- GroupLevel:

  level of grouping variable

- Numerator:

  number of flags in group

- Denominator:

  total subjects in group

- Metric:

  calculated rate/metric value

- Score:

  statistical score

- Flag:

  ordinal flag to be applied

## Source

Generated from `analyticsSummary.csv` dataset in the `gsm` package.
